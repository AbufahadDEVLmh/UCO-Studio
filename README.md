# 🚨 UCO Studio v2.0

تطبيق مكتبي احترافي مستقل لإنشاء وإدارة تقارير الاستخبارات والعمليات السرية (**Undercover Officers**) لسيرفرات **FiveM** و **GTA RP**.

---

## 🌟 المميزات
- **يعمل مباشرة بدون تثبيت أو متصفح:** ملف تنفيذي مستقل (`UCO_Studio.exe`) لنظام Windows 10 / Windows 11 (64-bit).
- **جاهز بخانات فارغة:** يبدأ البرنامج بجميع الحقول فارغة لتبدأ كتابة تقريرك فوراً.
- **5 قطاعات أمنية و4 أنماط عرض:** يدعم `LSPD` و`FIB` و`CIA` و`SWAT` وقطاعاً مخصصاً بالكامل، مع تحكم كامل في المسميات وإظهار/إخفاء أي قسم.
- **تصدير مباشر:** حفظ التقرير كصورة `PNG` أو ملف `HTML` على سطح المكتب، أو نسخ قالب ديسكورد جاهز بنقرة زر.

---

## 🚀 التشغيل والتحميل
1. حمّل `UCO_Studio.exe` مباشرة من المستودع أو من **[آخر إصدار (Release v2.0)](https://github.com/tolld597/UCO-Studio/releases/latest)**.
2. افتح `UCO_Studio.exe` مباشرة وابدأ إعداد تقريرك.
